## 2. 目标与三条原则

### 三个目标（同步推进，有主次）

1. **具备 Java 后端开发能力**：能独立完成一个有数据库、有接口、有业务逻辑的后端项目，并且能解释代码为什么这样写。
2. **达到实习求职的准备水平**：掌握常见数据结构与算法、MySQL、Redis、Spring Boot、计算机网络、操作系统等知识，并有讲得清楚的项目经历。
3. **成为会用 AI 的开发者**：能让 AI 帮忙读代码、定位 Bug、写测试、设计接口；同时能审查代码、发现漏洞、验证结果，不依赖 AI 才能写程序。

主次关系：**Java 后端能力是主线，计算机基础是底座，AI 工具能力是贯穿始终的加速器。**

### 三条执行原则

- **不换主线教材。** 继续用黑马 2026 版，遇到听不懂的地方单独查资料，不再并行追第二套课程。
- **不换主项目。** 所有学到的知识都往校园二手交易平台上落。学生信息管理系统只作为早期练习载体，已退出主线。
- **用验收驱动进度。** 某阶段的验收任务做不出来就先补漏洞，不为日期好看进入下一阶段；已经掌握的内容通过验收后可以直接跳过，不重复看完整章节。

### 24 周之后按优先级补

1. Java 集合底层、泛型、反射、JVM、并发与线程池。
2. MySQL 索引与事务原理、Redis 常见使用场景。
3. 操作系统、计算机网络、数据结构与算法（配合刷题）。
4. 按目标岗位再看消息队列、微服务、性能优化。
5. 后端基础稳定后，再学 Java 调用大模型 API、RAG、Agent 应用开发。

## 5. 长期项目：校园二手交易与互助平台

**定位**：面向大学校园的二手物品交易与日常互助平台，学生可以发布闲置物品、寻找所需商品，后续再扩展交易流程和校园互助功能。

**技术方向**：Java → MySQL → Spring Boot → Redis 等后端技术，之后按需加入前端与 AI 功能。

### 版本路线

| 版本 | 内容 | 对应阶段 | 练习重点 |
|---|---|---|---|
| V0.1 商品管理程序 | 控制台实现商品新增、展示、查询、删除 | Java 基础 | 类与对象、封装、集合、方法拆分、输入校验、异常 |
| V0.2 数据库与后端接口 | 商品存入 MySQL，用 Spring Boot 提供增删改查接口，加分页、参数校验、错误处理 | MySQL + Spring Boot | SQL、HTTP、JSON、REST API、分层开发 |
| V0.3 基础交易平台 | 用户注册登录、发布商品、商品详情、搜索、分页、基础权限控制 | 项目深化 | 用户与商品关系、业务逻辑、接口设计、测试 |
| V1.0 可展示的完整项目 | 订单流程、个人商品管理、管理员功能、日志、测试、部署 | 实习准备 | 完整业务流程、项目质量、部署运行、面试讲解 |
| V2.0 进阶扩展 | 校园互助任务、站内消息、Redis、AI 商品推荐或校园问答助手 | 后续 | 性能优化、复杂业务、AI 应用开发 |

**每次只做当前能力范围内的功能，不要把项目变成第二套庞大课程。**

### 当前代码结构

```text
Main           负责启动程序、组织操作
  └─ ProductManager   负责新增、展示、查询、删除商品
       └─ Product      表示一个具体的商品
```

学完集合后用 `ArrayList<Product>` 保存多个商品；学完数据库后再换成真正的持久化。

### 每加一个功能，都走这五步

1. **写需求**：这个功能解决什么问题？输入和输出是什么？
2. **画流程**：先用文字或流程图说清业务过程。
3. **自己实现**：能写多少写多少，不要求一次写好。
4. **AI 辅助**：让 AI 找遗漏、审查代码、生成测试用例。
5. **验收提交**：自己运行、测试、修复，再提交 Git。

### 项目达到"能拿出去讲"的硬标准

- Git 仓库干净，提交记录能看出迭代过程。
- README 写明功能、技术栈、运行方式、关键设计。
- 有接口文档、数据库设计说明、测试（哪怕是手工测试清单）。
- 能当场演示运行效果，能独立讲解关键代码。
- AI 参与了哪些环节、你怎么验证结果，也要能说清楚。

## 6. AI 能力升级路线

### 四个阶段

| 阶段 | 时间 | 做什么 | 训练标准 |
|---|---|---|---|
| 1. AI 学习助教 | 第 1–8 周 | 提问、要提示、理解报错、生成练习题 | 能说清自己已会什么、哪里不懂、希望 AI 怎么帮 |
| 2. AI 调试与测试搭档 | 第 9–16 周 | 提供完整报错、相关代码、预期与实际结果，让 AI 缩小排查范围 | 能验证 AI 的修复方案，知道它为什么有效、还有哪些边界情况 |
| 3. AI 协作开发 | 第 17–24 周 | 让 AI 拆分需求、设计接口、生成测试、审查变更；开始用 Codex 类工具，从小任务起步 | 能下明确任务、检查修改范围、跑测试、审查 diff、必要时回滚 |
| 4. 开发 AI 应用 | 后续进阶 | 模型 API、结构化输出、工具调用、RAG、Agent，以及超时、重试、日志、成本与安全控制 | 能把 AI 功能作为可靠服务接进 Java 后端，而不是只跑通一次模型调用 |

### AI 的三个使用档位

- **学习模式**：只给提示、反问、分步骤解释。前期以这个为主。
- **协作模式**：你先写代码，AI 补测试、审查、改进。
- **工程模式**：在你判断得了结果的前提下，让 AI 协助完成较完整的功能，并由你负责验收。

### 四条常用提示词

**1. 学习一个 Java 概念**

```text
我有 C 语言和 Python 基础，目前正在学习 Java。请解释【知识点】。先用简单例子说明，
再指出它与 C/Python 的关键区别，最后给我两道由浅入深的练习。
先不要给练习答案，等我尝试后再点评。
```

**2. 让 AI 帮你调试**

```text
请先不要直接重写我的代码。请根据下面的代码、报错和预期结果，分析最可能的原因，
指出相关代码位置，并给我一个最小修改方向。如果有多个可能原因，请按可能性排序。
最后告诉我怎样验证修复有效。

代码与报错：
```

**3. 让 AI 审查你的代码**

```text
请以 Java 后端代码审查员的身份检查下面的代码。优先检查逻辑错误、空值和边界条件、
异常处理、SQL 安全、权限问题及可测试性。请区分确定的问题和潜在风险，按严重程度排序；
每个问题说明原因、复现方式和建议。不要为了代码风格而随意重写。
```

**4. 让 AI 帮你做阶段验收**

```text
我正在学习 Java，当前阶段是【阶段】，已学习【知识点】，自己完成了【功能】。
请不要只夸我，请通过提问和小任务检查我是否真的掌握。一次只问一个问题；
如果我答错，先给提示，再解释。最后列出我的薄弱点和下一步练习建议。
```

### 三条长期红线

- 不要把密码、API 密钥、真实用户数据或敏感配置直接发给 AI。
- 对 AI 生成的依赖、代码、命令保持审查习惯，不理解的破坏性操作坚决不执行。
- 重要功能必须有测试或可复现的验证步骤；AI 说"已经修复"不等于程序真的正确。

## 7. 学习方法：固定闭环

### 单次学习用 90 分钟法

| 时长 | 做什么 |
|---|---|
| 15 分钟 | 复习与理解：回忆上次内容，确定今天只解决一个核心问题 |
| 35 分钟 | 独立编码：不照抄视频，先写自己的实现 |
| 20 分钟 | 测试与 AI 辅助：先自己定位错误，再让 AI 提示，并验证每条建议 |
| 20 分钟 | 复盘与小改动：用自己的话解释代码，再改一个小需求 |

### 每周的节奏

- **第 1 天**：学新知识，看课程并自己敲，记下不懂的地方。
- **第 2 天**：独立练习，合上视频做小题，改需求，记录卡点。
- **第 3 天**：推进项目，把本周知识落成一个小功能。
- **第 4 天**：AI 辅助、复盘与测试，复述原理，修问题，提交 Git。

四个学习日可以分散在一周里，也可以切成更短的时段。

### 每周复盘四问

1. 这周我能独立写出什么？
2. 哪些知识点只是听懂了，实际还不会？
3. 我遇到过什么 Bug，怎么定位和解决的？
4. 下周最值得解决的一个问题是什么？

### 每周验收清单（6 条）

- [ ] 能不看视频，解释本周最重要的 3 个知识点
- [ ] 至少独立完成 2 道练习或 1 个小功能
- [ ] 能说明本周遇到的一个错误及其解决方法
- [ ] 至少把 1 个功能提交到 Git
- [ ] 让 AI 审查过自己的代码，并验证至少 1 条建议
- [ ] 写下下周最需要补的 1 个薄弱点

这张清单不是打卡 KPI。某周只完成四项就记录原因，下一周继续。

### 卡住时的四级求助机制

1. **只给方向**：告诉你该考虑哪些知识点，不给写法。
2. **给出思路**：拆解步骤，但不给完整代码。
3. **局部示例**：只展示一个关键语法或局部代码，剩下的自己补。
4. **完整讲解**：多次尝试仍卡住时才看完整方案，看完要合上答案自己重写一遍。

### 可长期使用的教练提示词

```text
你现在是我的 Java 学习教练。

我的背景：有 C 语言和 Python 基础，目前正在学习黑马程序员 2026 版 AI + Java 课程，
学到了面向对象。我希望以 Java 后端就业为目标，稳扎稳打地提升独立编码能力。

请遵守以下规则：
1. 我没有明确要求完整答案时，不要直接给我完整代码。
2. 先让我描述思路，再指出思路中的问题。
3. 我卡住时，按"方向提示 → 解题步骤 → 局部示例 → 完整讲解"的顺序逐步帮助我。
4. 解释 Java 特有语法时，可以联系 C 和 Python 的概念，但要指出区别。
5. 优先帮我理解错误原因、边界情况和调试方法，不只给出能运行的代码。
6. 每完成一个知识点，给我一道独立练习，检查我是否真正掌握。
7. 根据我的实际表现判断薄弱点，不要默认我已经掌握，也不要重复讲我能独立完成的内容。
```

## 9. 怎么判断自己接近求职要求

| 能力层次 | 应该做到什么 |
|---|---|
| Java 基础合格 | 独立完成中小型程序，理解集合、异常、面向对象，能调试代码 |
| 后端项目入门 | 能用 Spring Boot + MySQL 实现完整业务接口，掌握基本测试和 Git |
| 实习投递准备 | 有完整项目、算法练习、计算机基础，能解释项目设计并回答相关技术问题 |

进入第二层就可以开始看目标公司的实习 JD，了解真实差距；进入第三层后开始有计划地投递，并根据面试反馈调整重点。

**现在不要做的事**：不要急着卷微服务、大模型底层；不要拿大厂资深工程师的标准要求自己；不要为了赶进度连看多集视频却不动手。
